# Learning Notes

Structured notes for building practical fluency in digital public infrastructure and government implementation.

## Learning tracks

- Government architecture: Centre, state, district and local institutions
- DPI foundations: identity, payments, registries, data exchange and open networks
- Entrepreneurship rails: Udyam, GeM, ONDC, Account Aggregator and related state systems
- Responsible data use: consent, privacy, security and inclusion
- Government delivery: schemes, PMUs, RFPs, procurement, budgeting and monitoring
- Applied research: interviews, process mapping, theory of change and evaluation

## Note template

Each note should answer:

1. What problem does this system address?
2. Who owns, operates and uses it?
3. How does it work in plain language?
4. Where does district implementation break?
5. What does it mean for an entrepreneur?
6. Which questions still require evidence?
