# System Designs

Practical designs for improving entrepreneurship-service delivery using existing institutions and digital infrastructure.

## Design artefacts

- Entrepreneur journey maps
- Stakeholder and responsibility maps
- Service blueprints
- Referral and escalation protocols
- Theories of change
- Minimum data structures
- Monitoring dashboards
- Assisted-access models
- Grievance and accountability flows

## Design test

Every proposal should explain:

1. Which real problem it solves
2. Why an existing process cannot solve it unaided
3. Which institution owns each step
4. Which existing digital rails can be reused
5. What data is necessary—and what is not
6. How excluded users receive assistance
7. How success, failure and grievances are measured

The objective is orchestration, not another standalone portal.
